# Jogo de Adivinhação de Número
Um jogo simples de linha de comando feito em Python, onde o computador sorteia um número secreto e o jogador tenta adivinhar através de dicas.
 
## Como funciona
O programa sorteia um número aleatório entre 1 e 100
O jogador digita palpites até acertar
A cada tentativa, o programa avisa se o palpite foi muito alto ou muito baixo
No final, é exibido quantas tentativas foram necessárias para acertar

## Tecnologias
Python 3
Módulo `random` da biblioteca padrão

 
## O que pratiquei neste projeto
Estruturas de repetição (`while`)
Estruturas condicionais (`if` / `elif`)
Conversão de tipos (`str` para `int`)
Manipulação de variáveis e contadores
f-strings para formatação de saída

## Sobre
Projeto feito como exercício de fixação de lógica de programação.
